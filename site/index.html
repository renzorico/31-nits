      How is this made?

      Inside Airbnb, an independent project, publishes scraped Airbnb listings. It offsets each point by up to 150 m to protect hosts' privacy, so a dot is never an address. No host or listing is identified on this page. District shares are computed from the neighbourhood figures the map export also uses.

                    How this was made, and what it cannot show.

                    Every number on this page is computed from public files by an open Python pipeline, with its numerator and denominator in the published data. The data shows settings, counts and timing. It does not show causes, how long guests actually stay, or whether any listing breaks a rule.
